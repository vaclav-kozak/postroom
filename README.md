# Postroom

Postroom is a self-hosted [MCP](https://modelcontextprotocol.io/) server that gives Claude (or
any MCP client) access to all your mailboxes, calendars, tasks and contacts: IMAP and Google
mail, CalDAV and Google Calendar/Tasks, CardDAV and Google Contacts. It speaks Streamable HTTP,
ships its own OAuth 2.1 authorization server, has an owner-only admin web UI and keeps every
stored secret encrypted at rest.
